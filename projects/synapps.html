SYNAPPS

// Icon stacks per il desktop Windows. Raggruppa app, file e cartelle dietro una sola icona — tieni premuto per aprire a ventaglio, clicca per lanciare.

↗ Vedi su GitHub Windows Desktop
Il Problema

Il desktop era un casino.

Decine di icone sparse, cartelle di accesso rapido che si moltiplicano, nessun modo intelligente di raggruppare le cose che usi insieme. Synapps risolve il problema con un'idea semplice: un'icona sola che ne nasconde molte.

Come Funziona

Tieni → apre. Clicca → lancia.

Ogni "synapp" è uno stack visivo che raggruppa app, file o cartelle correlate. Un tap breve lancia l'elemento principale. Un tap lungo fa aprire tutto il gruppo a ventaglio — puoi scegliere cosa aprire senza cambiare desktop.

Funzionalità
  • Raggruppa app, file e cartelle in un singolo stack sul desktop
  • Hold per aprire a ventaglio, click per lanciare direttamente
  • Integrazione nativa con Windows — nessun processo pesante in background
  • Personalizzazione dell'icona e del nome dello stack
  • Gestione drag & drop per aggiungere elementi allo stack
Cosa ho imparato

UX minimalista, integrazione OS.

La sfida principale era rendere il fan-out fluido e non invasivo: non deve sembrare un'app in più, ma una feature naturale del desktop. Ho lavorato molto sull'animazione e sul timing dell'apertura a ventaglio.

Integrare tool con il filesystem di Windows e gestire i percorsi in modo robusto mi ha insegnato molto sulla differenza tra un prototipo e qualcosa che funziona davvero su hardware reale.
